## My Projects

### 1. Personal Portfolio

* **Description:** A comprehensive personal portfolio website showcasing my skills, projects, and professional journey as an AI/ML enthusiast and data science professional.
* **Features:**
    * Responsive design with modern UI/UX
    * Project showcase with detailed descriptions
    * Skills and technology stack display
    * Contact form and social media integration
    * Interactive elements and animations
* **Technologies Used:** HTML5, CSS3, JavaScript, Bootstrap
* **Link:** [Personal Portfolio](https://krishnasingh-28.github.io/)

### 2. Face Recognition App

* **Description:** An advanced computer vision application that detects and recognizes faces in real-time using deep learning algorithms.
* **Features:**
    * Real-time face detection and recognition
    * Multiple face detection in single frame
    * Face encoding and matching capabilities
    * User-friendly interface with webcam integration
    * High accuracy recognition system
* **Technologies Used:** Python, OpenCV, dlib, face_recognition library, Streamlit
* **Link:** [Face Recognition App](https://github.com/krishnasingh-28/Face-Recognition-App)

### 3. Image Classification

* **Description:** A deep learning model that classifies images into different categories using convolutional neural networks.
* **Features:**
    * Trained on a custom dataset
    * High accuracy in classification
    * Multi-class image categorization
    * Data preprocessing and augmentation
* **Technologies Used:** TensorFlow, Keras, Python
* **Link:** [Image Classification](https://github.com/krishnasingh-28/Image-Classification)

### 4. Product Recommendation System

* **Description:** A machine learning model that recommends products to users based on their past behavior and preferences using collaborative filtering techniques.
* **Features:**
    * Collaborative filtering approach
    * Personalized recommendations
    * User-item matrix analysis
    * Similarity-based recommendations
* **Technologies Used:** Python, Pandas, Scikit-learn
* **Link:** [Product Recommendation System](https://github.com/krishnasingh-28/Product-Recommendation-System)

### 5. Password Generator

* **Description:** A simple yet powerful tool to generate strong, random passwords to enhance security.
* **Features:**
    * Customizable password length
    * Inclusion of uppercase, lowercase, numbers, and symbols
    * Copy-to-clipboard functionality
    * Secure random generation algorithm
* **Technologies Used:** Streamlit, Python
* **Link:** [Password Generator](https://github.com/krishnasingh-28/password-generator)

### 6. Weather Forecast App

* **Description:** A web application that provides real-time weather forecasts for any location worldwide with detailed meteorological information.
* **Features:**
    * Search for weather by city name
    * Displays temperature, humidity, and wind speed
    * 5-day forecast view
    * Interactive weather maps
* **Technologies Used:** React (Under-Construction), OpenWeatherMap API
* **Link:** [Weather Forecast App](https://github.com/krishnasingh-28/weather-forecast-app)
